## インストールと更新

Android のブラウザから APK をダウンロードして開き、システムの案内に沿ってインストールしてください。互換性のある内容更新は起動時に確認・ダウンロードし、次回起動で反映します。すぐ確認する場合は App の「設定 → 更新」を開きます。

新しい APK が必要な場合も、上の固定ダウンロードページから取得できます。記録はスマートフォン内に保存されるため、更新時は App を削除せず上書きしてください。アカウントでのバックアップ・端末間同期は準備中です。

## 体験版について

正式な物語・題庫やキャラクターの完全な動作アニメーションは制作中です。Android の機種ごとの表示・操作・OTA 更新は追加確認が必要です。iPhone 用のインストーラーではありません。

この repository には配布用 APK、チェックサム、リリース案内のみを置きます。App のソースコードは含みません。
